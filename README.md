# 解说劳酬联合统计的安全披露

金额用百元整数；合计等于采纳的到手正额减明确追回额。表中空金额用 `?` 表示，目前只知道在该期议定上下限中；同人员、期间、工作出现后来带正数的补记时取最新正额或未知记录，负额是单独的追回。`complete=0` 的统计组不能与完整组作确切差异比较。公开在职名单中的 `public_group`、`new_group`、`seniority` 可被接收人使用。`prior` 是已发出或公开可看，`preview` 尚未发，`void` 不计发布。发件对象 `public` 是所有受众可见，`workgroup` 仅合作组可见；对 public 新发件也须检查 workgroup 的合并视角。包住真实合计的金额区间含两个端点，宽度为最大值减最小值；内部比较请求可以约定最大宽度。按当期 `rules` 判断最低人数和每人在各期受保护总额的最小可行区间宽度；推理使用接收方已掌握的分组和合法单人金额边界，不依赖私有真值作为公开约束。`+` 分隔合并组；`*` 表示不限制。候选表中空区间代表希望根据本期输入计算，不是发布数据。

## 数据包

`sample/` 是本地合成的业务记录，均为 UTF-8 CSV；`table-format.json` 给出各表的列顺序与标量类型，`str` 中 `-` 表示不适用，逗号分隔多值。不同表中同名业务标识用于关联，具体含义见上文。资料入口只检查表头和格式，不对业务状态作判断。

## 运行

使用 Python 3.11 标准库，不需要安装三方依赖。读取样例与运行资料检查：

```sh
python3 intake.py
python3 -m unittest -v
```

也可以将同格式的资料目录作为 `intake.py` 的位置参数。
